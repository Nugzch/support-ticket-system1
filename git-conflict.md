# Описание конфликта слияния

- **Конфликтующие ветки:** `master` и `feature/sla-notifications`
- **Файл с конфликтом:** `project-notes.md`
- **Причина возникновения:** В обеих ветках параллельно изменили строку спецификации формата передачи данных (REST JSON vs gRPC) и стек интеграций (RabbitMQ vs Telegram).
- **Способ разрешения:** Конфликт разрешён вручную объединением требований: внедрена гибридная архитектура (REST + gRPC) и сохранены обе интеграции.
